# Contributing

Thanks for helping improve the AI Content Design Handbook.

## Good contributions

- **Corrections** when a company updates its public guidance. Include the link to the updated source.
- **New examples** from public design systems, style guides, or research, paraphrased and linked.
- **New templates** for content patterns that aren't covered yet.
- **Case studies** from your own work, with anything confidential removed.

## Rules for company examples

1. **Public sources only.** Design systems, style guides, published research, and official documentation.
2. **Paraphrase, attribute, and link.** Quote only short UI strings, and always link the source.
3. **Don't infer.** If the source doesn't say it, the handbook doesn't either.
4. **Note disagreements.** When companies' guidance conflicts, say so rather than picking a side silently.

## Style

Follow the handbook's own guidance: plain language, sentence-case headings, specific verbs, and no blame in error examples. See the [Voice and Tone Framework](style-guides/voice-and-tone-framework.md).

## How to submit

1. Fork the repo and create a branch.
2. Make your change and check that relative links still work.
3. Open a pull request describing what changed and why, with sources.

See [Git Workflow for Content Designers](workflows/git-workflow.md) if you're new to pull requests.
